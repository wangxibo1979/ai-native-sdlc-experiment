# Bounded experiment design

Fresh spec-only A, independent target reviewer, static maps before execution, reuse established blind-review evidence, then local contract negative controls. A requirement-map artifact is not an implementation plan. tasks.md remains the sole formal progress list.

The contract is a trusted, versioned experimental input. Hashes detect accidental drift, not a malicious actor allowed to rewrite the contract, runner and review together. New local results do not prove remote CI merge blocking.
